# 圆锥曲线

## 三类曲线
- 椭圆：a² = b² + c²，离心率 e = c/a ∈ (0,1)
- 双曲线：c² = a² + b²，渐近线 y = ±(b/a)x
- 抛物线：y² = 2px，焦点 (p/2, 0)

## 通用套路
1. 设直线方程（分类讨论斜率存在与否）
2. 联立得一元二次方程，**先写判别式 Δ > 0**
3. 韦达定理代入目标式
4. 定值/定点问题：先猜后证

运算量大，建议配合 [[平面向量]] 降低计算量，错题见 [[数学-错题索引]]。
