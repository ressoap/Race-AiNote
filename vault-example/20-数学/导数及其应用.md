# 导数及其应用

## 定义与几何意义
f'(x₀) 是曲线在 x₀ 处切线的斜率。

## 运算
- 四则运算、复合函数链式法则
- 常见函数导数表

## 三大应用
1. 单调性：f'(x) > 0 递增
2. 极值：导数为零 + 左右变号
3. 最值：极值与端点值比较
