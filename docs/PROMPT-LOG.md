# Prompt 链快照

> 赛题要求：至少 3 个核心功能迭代的完整 Prompt 链（提问 → AI 给出的方案 → 如何引导修复 → 验收）。
> 本文按时间顺序记录真实迭代过程，每条都对应仓库里的一次 commit。
> 记录原则：保留失败与返工，不美化。

---

## 链路 0 · 立项与规格（对应 `PROMPT.md`、`可行性分析.md`）

**Prompt**

> 用零依赖前端技术（HTML + CSS + 原生 JS + Canvas 2D）复刻 Obsidian Graph View，最终交付单文件 HTML。
> 需要：自定义力导向（中心力/排斥/连线弹簧/连线距离/碰撞）、拖拽平移缩放、悬停邻居高亮、
> 全局/局部图谱、搜索语法（path: file: tag: content: -排除 OR）、四类筛选、颜色分组、
> 箭头/文字淡出/节点大小/线宽、明暗主题、设置持久化。

**AI 产出**：一份 12 条验收清单 + 界面结构草案。

**人工纠偏**

1. ✓ 接受「单文件交付」作为硬约束——它让演示视频里「双击就能跑」变成真的。
2. ✗ 拒绝「先做界面再补数据」的顺序：数据模型决定了渲染与筛选的所有边界。
3. 追加约束：**所有初始位置必须由路径哈希推导，不许用 `Math.random()`**——
   否则「重新布局」每次结果不同，录像与截图无法复现。这一条后来成了物理引擎的验收项。

**验收**：`PROMPT.md` 定稿；`可行性分析.md` 给出 MVP 顺序（AI 整理 → 拍题 → 图谱统一）。

## 链路 1 · Markdown 解析层（commit `feat(vault)`）

**Prompt**

> 实现 vault.js：把一组 `{path, content}` 解析成图模型。
> 必须处理：frontmatter 的 title/tags/aliases；`[[目标|别名#锚点]]`；`![[嵌入]]`；
> 正文 `#标签`（支持 `#a/b`）；代码块与行内代码里的双链**不能**算链接；
> `https://` 开头的双链不算内部链接；解析不到的链接要变成「未创建节点」而不是丢弃。
> 解析规则要贴近 Obsidian 的最短路径匹配：先全路径，再文件名，同名取第一个。

**AI 第一版问题**

- 用 `split('\n')` 直接扫全文，把围栏代码块里的示例双链也解析成了真链接；
- `# 一级标题` 被当成标签；
- 别名 `[[笔记|显示名]]` 只取了整串，导致大量「未创建链接」误报。

**引导修复**

> 先把围栏代码块整体替换成等长空白（保留换行，避免行号错位），再做链接与标签抽取；
> 标签正则要求 `#` 前面是行首或空白/括号，且 `#` 后紧跟字母数字，因此 `# 标题` 与 URL 里的 `#section` 都不会命中。

**验收**：`tests/vault.test.js` 11 项断言（含代码块、别名、多级路径、去重、度数）。

## 链路 2 · 查询语法（commit `feat(query)`）

**Prompt**

> 写一个不依赖任何库的查询解析器，支持 `path: file: tag: content: -排除 OR "带空格" /正则/`。
> 要求：解析结果可被 `describe()` 打印出来做调试；非法正则不能让页面崩溃。

**AI 第一版问题**

- `OR` 切分用 `split(' OR ')`，把引号里的 `OR` 也切了；
- `/正则/` 里出现的 `OR` 同样被误切；
- 非法正则 `/[unclosed/` 直接抛 `SyntaxError`，整个搜索框一输入就白屏。

**引导修复**

> 自己写单遍扫描：维护 `quoted` 与 `inRegex` 两个状态位，只有两者都为假时才认为遇到顶层 `OR`；
> 正则先用 `try { new RegExp } catch` 兜底，编译失败就退化成「不匹配」而**不是**「抛出异常」。

**验收**：`tests/query.test.js` 9 组用例，含非法正则的安全降级断言。

## 链路 3 · 力导向引擎（commit `feat(physics)`，两次返工）

**Prompt**

> 写一个确定性力导向模拟：排斥力 + 连线弹簧 + 中心引力 + 碰撞分离。
> 初始位置用 FNV-1a 哈希推导，禁止随机数；碰撞检测用网格分区，不要全量 O(n²)；
> 拖拽中的节点必须被冻结；任何情况下不允许出现 NaN。

**AI 第一版问题（单测抓出来的）**

1. 两个节点坐标完全重合时，`dx = dy = 0`，分离方向的单位向量算出 `NaN`，
   节点从此飞出画面 —— 单测 `重合节点会被碰撞分离推开` 报「距离 0.00」。
2. 被拖拽冻结的节点虽然速度被清零，但碰撞分离直接改坐标，还是会被邻居推开 ——
   单测 `固定节点不移动` 报 `14.26 !== 10`。
3. `linkStrength` 参数被除了两次 1000，滑杆拉到最大也几乎没有效果。

**引导修复**

> 1) 重合时用 `hash(a.id + '|' + b.id)` 生成确定性分离角，既避免 NaN 又保持可复现；
> 2) 分离函数里判断 `fixedId`：固定的节点只给对面推两份位移，自己不动；
> 3) 参数只在 UI 层做一次量纲映射（滑杆 1–20 → 0.001–0.020），引擎内部按原值使用。

**验收**：`tests/physics.test.js` 9 项，含 NaN、边界、冻结、空数据、网格覆盖度。

## 链路 4 · 界面与「首屏就是半成品」问题（commit `feat(ui)`）

**Prompt**

> 把渲染层和交互装配起来：文件树、搜索条、设置面板、笔记预览、明暗主题、设置持久化。
> 另外要能读取**真实**的笔记目录：目录选择器 + `webkitdirectory` 兜底 + 拖放目录递归读取。

**AI 第一版问题（截图验证发现）**

1. 首屏弹出了空白预览弹窗，画布上还有一圈虚线框 ——
   根因是 `.modal { display: grid }` 把 `hidden` 属性覆盖掉了，**CSS 的 display 优先级高于 hidden 的默认样式**。
2. 首屏图谱节点巨大、连线拉满全屏：`fitView()` 在模拟还没收敛时就做了自适应，
   之后节点继续聚拢，视野就停在了一个过时的包围盒上。
3. 标签全部不可见：阈值按「屏幕半径」判定，而自适应后半径只有 8px，永远达不到 35px 阈值。

**引导修复**

> 1) 加一条全局兜底 `[hidden] { display: none !important; }`；
> 2) 重建图时**先同步预热 140 tick 再 fit**，并在模拟真正收敛（`paused`）后再 fit 一次；
> 3) 标签可见性改成按缩放比例判定（`fadeThreshold = 0.28 + textFade/100`），
>    并新增标签矩形避让，重叠的标签直接跳过绘制，避免文字糊成一团。

**验收**：jsdom 冒烟测试（无报错、41 节点 / 96 连线）+ 1440×900 截图人工比对。
