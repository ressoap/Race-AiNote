    外观

    黑夜模式文字自动转为浅色；跟随系统会随系统明暗实时切换。

    换背景色不影响文字对比度。

    AI 模式

    不填 Key 时，问答面板走本地分析（检索 + 规则），功能有限但离线可用。填了之后才是完整 AI。

    模型

    图片消息会优先使用视觉模型；只有支持图片输入的模型才能识别图片内容。

    默认关闭：格式整理走确定性本地规则，绝不会改动文字。开启后由模型排版， 但结果必须通过「去掉标记后逐字一致」的校验，改动过一个字就自动回退本地结果。

    ⚠ Key 只写入本浏览器 localStorage，不会上传到本项目的任何服务器，也不会进 Git 仓库。公共电脑上不要填。

    插件

    插件是一段运行在本页面的 JS，通过受限 API 注册按钮、命令和挂件。 它拥有和本页面相同的权限，只装你信任的代码。
